# Anotações

(web)[https://lsbrelww.github.io/anotacoes/]

Documentação para preenchimento diário e supostamente constante dos desenvolvimentos, atividades, iniciativas e conversas realizadas dentro do ambiente de trabalho Madeira Madeira, bem como também, comentários de cunho menos formal para trazer uma visão pessoal e critíca sobre alguns pontos dos tópicos citados.

Este projeto, é uma continucação direta de sua versão "plugada", na maquina local do usuário lsbrelww(eu) onde eram regidas algumas documentações, tanto das minhas atividades, quando de conversas que ocorriam internamente, quando digo conversas me refiro a reuniões e calls para resolução de determinadas demandas.

Sobre a parte técnica deste projeto, ele está sendo versionado utilizando o github, com o usuário da companhia. Utilizando o 'mdbook', ferramenta escrita em Rust para automação deste ambiente de documentação, ou seja, a parte estrutural destas anotações é provida pelo mdbook, somente a edição e adição dos arquivos com extensão .md é feita periodicamente.

Para que seja acessível de forma mais pratica será utilizado o githubpages, que visa trazer acessibilidade para acesso de determinadas documentações via web. Assim mesmo quando em outro computador, será possível acessar estas infos. Por isso é essencial que nesta documentação, nenhuma informação sensível seja exposta.
